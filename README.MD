# Tamil Language Model Bias Analysis

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)]()

Comprehensive analysis of social biases in Tamil language models across:
- Gender
- Caste
- Religion
- Dialects
- Regional variations

## Key Features

- 🧪 Test suite covering 6 bias dimensions in Tamil
- 📊 Comparative analysis of Tamil-BERT vs Multilingual-BERT
- 📈 Statistical significance testing
- 🛠️ Proposed mitigation strategies

## Quick Start

```bash
git clone https://github.com/tamil-lm-bias-analysis/tamil-lm-bias-analysis.git
cd tamil-lm-bias-analysis
pip install -r requirements.txt

# Run analysis
python tamil.py
